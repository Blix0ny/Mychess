# Ход конём — шахматы для всех

Шахматная игра в одном файле `index.html`: работает в браузере телефона и компьютера, без сервера и без регистрации на чужих сайтах.

## Что внутри

- **Игра:** против робота (8 соперников с разной силой), вдвоём на одном телефоне, онлайн с другом по коду приглашения.
- **Школа с нуля:** 12 интерактивных уроков для тех, кто никогда не играл.
- **Дебюты и ловушки:** разборы с пояснениями к ходам.
- **Задачи дня:** три задачи на мат каждый день, серия дней.
- **Шахматные часы:** 1, 3, 5, 10 минут и «3+2».
- **Оценка ходов** (блестящий, хороший, зевок и т. д.), подсказки, рейтинг, анимации, звуки.
- **Профиль:** email, ник, статус, описание, аватарка. Всё хранится только в браузере пользователя.

## Как выложить на GitHub Pages

1. Создайте аккаунт на github.com и новый **публичный** репозиторий (например, `chess`).
2. Загрузите в корень репозитория файлы из этой папки: `index.html` (обязательно) и, желательно, `manifest.webmanifest`, `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.
   Кнопка: **Add file → Upload files → Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

Чтобы поставить игру на экран телефона: откройте сайт в браузере и выберите «Добавить на главный экран» (Android) или «На экран Домой» (iPhone, через меню «Поделиться»).

## Онлайн с другом

Сервера нет, поэтому игроки соединяются напрямую (WebRTC), обменявшись кодами:

1. Первый игрок: **Новая игра → Онлайн → Создать приглашение** и отправляет код другу.
2. Друг открывает тот же сайт, вставляет код, нажимает **Принять приглашение** и отправляет свой ответ.
3. Первый игрок вставляет ответ и нажимает **Подключить ответ**.

Если у обоих сложная мобильная сеть, соединение может не установиться. Помогает общий Wi-Fi или другой оператор. Поиск незнакомых игроков потребует собственного сервера.

## Тег «Разработчик-CEO»

В профиле тег выбирается только при вводе кода. В репозитории хранится не сам код, а его SHA-256 (константа `DEVHASH` в `index.html`). Чтобы задать свой код, посчитайте хэш:

```
echo -n "ваш-код" | sha256sum
```

и подставьте результат в `DEVHASH`. Это защита от случайного выбора, а не настоящая защита: всё работает в браузере пользователя.

## Приватность

Профиль, рейтинг и прогресс хранятся в `localStorage` браузера. Никакие данные не отправляются на сервер. Для соединения WebRTC используется общедоступный STUN-сервер Google (`stun.l.google.com`).
